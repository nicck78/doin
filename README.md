# doin

<img src="./public/logo.png" alt="doin 图标" width="72" />

**把待办、七天安排和专注记录放在自己设备上的小工具。** 提供 Windows 64 位绿色版和 Android 体验版；目前没有账号或自动同步。

> 当前公开版本：`1.1.0-beta.1`（体验版）。已在一台 Windows 电脑和 HONOR 80（Android 15）上做有限试用，其他设备和长期使用仍待验证。

## 下载与开始使用

前往 [读者体验版发布页](https://github.com/nicck78/doin/releases/tag/v1.1.0-beta.1)：

| 设备 | 下载文件 | 第一步 |
| --- | --- | --- |
| Windows 64 位 | `doin-reader-1.1.0-beta.1-windows-x64.zip` | 解压**整个文件夹**，打开其中的 `doin-reader.exe`。无需安装 Node.js。 |
| Android | `doin-reader-1.1.0-beta.1-android.apk` | 在手机文件管理中打开 APK，按系统提示安装“doin 体验版”。 |

先用一条虚构任务试用，关闭后重新打开，确认任务仍在。重要数据请在“设置 → 导出备份”保存 JSON，并在文件管理器中确认文件确实存在。详细步骤、升级方法和常见提示见[安装与备份说明](./读者体验版-安装与备份.md)。发布页另附 `SHA256SUMS.txt` 供校验下载文件。

Windows 程序暂未做代码签名，系统可能显示“未知发布者”；请核对下载来源与文件校验值后自行决定是否运行。Android 是独立的体验版应用，不会覆盖早期自用调试版，两者数据也不会自动互通。

## 现在能做什么

- **今日**：查看和勾选当天任务，快速添加待办；电脑宽屏还会并排显示简易专注与当天日志。
- **全景**：查看可前后移动的七天安排。跨天任务以连续横条呈现；Android 七列中直接展开单日任务，标题可换行。还可以处理“待安排”和“历史未完成”任务。
- **专注**：使用正向秒表或倒计时，保存专注记录。HONOR 80 上短测过切到桌面和锁屏约 20 秒后返回，经过时间会计入或扣除；长期后台行为尚未验证。
- **日志与设置**：记录每日内容，切换浅色／深色与中英界面，导出或导入本地 JSON 备份。

| 功能 | Windows | Android |
| --- | --- | --- |
| 今日、七天全景、专注、日志 | 有 | 有 |
| 待安排与历史未完成任务 | 有 | 有 |
| 悬浮胶囊、专注简洁视图 | 有 | 无 |
| 手机切后台与锁屏后的短时计时补算 | 不适用 | 已在 HONOR 80 短测 |
| 锁屏到点系统通知、账号与云同步 | 无 | 无 |

## 数据怎样保存

任务、专注记录和日志保存在各自设备。电脑与手机之间可通过 JSON 文件**手动传输**。导入前会显示当前与来源的数据数量；确认导入后会**整体替换接收端数据，不会自动合并**两端新增内容。应用会尝试保存一份导入前恢复文件，但重要数据仍应另存到应用外部。备份是明文 JSON，请勿公开分享私人待办。

Windows 读者版使用独立的 `doin-reader` 用户资料目录，数据不随绿色版文件夹移动。Android 读者版的包名是 `com.doin.reader`，与早期调试版 `com.doin.personal` 并存。卸载应用或清除应用数据前，请先确认外部备份能找到。

## 已知范围

- 这是体验版；只在一台 Windows 电脑和一部 HONOR 80 上做过有限人工验证，不代表所有机型都已适配。
- 手机没有跨应用悬浮胶囊，也没有锁屏到点系统通知。长时间后台、应用被系统结束后的计时行为尚未验证。
- 没有账号、自动同步、冲突合并、iOS 版或应用商店版本。Windows 绿色版没有自动更新。
- 如遇问题，请先保留备份，再反馈系统版本、操作步骤和错误提示；不要发送私人任务内容。

## 开发者说明

普通读者直接使用上方安装包，无需运行以下命令。源码采用 React、Electron 和 Capacitor；日期规则与任务界面共用，桌面与 Android 的存储、文件操作分别接入。

在 Windows 开发环境安装 Node.js 后：

```bash
npm install
npm test
npm run build
npm run package:reader
```

`npm run package:reader` 生成完整的 `release/doin-reader-<版本>-windows-x64/` 文件夹，**不会直接生成发布用 ZIP**；发布前还需压缩整个文件夹并验证。`npm run dev` 会启动个人桌面开发版，可能读取和改动这台电脑原有的 doin 数据；需要调试时应先准备隔离的测试资料目录。`npm run package` 是早期个人桌面版的单独脚本。Android 正式 APK 需要仓库外保管的签名密钥和本机 Android 构建环境，不能用调试签名代替读者版签名；仓库不提供密钥或密码。

自动化测试覆盖日期窗口、跨天任务、备份数据、双语文本和计时规则。模拟休眠的测试只验证时间计算，不能代替真实电脑休眠或长时间手机锁屏测试。
