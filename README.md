## 📖 设计哲学

在生产力工具充斥着“功能冗余、算法打扰、强制登录与云端订阅”的当下，**doin** 选择回归个人数字生活的本质——**沉浸、纯粹、确定与自律**。

软件深度整合了：
1. **今日聚焦（Today's Focus）**：双栏人体工学排版，待办推进与常驻效率伴侣协同；
2. **多日全景（Multi-day Timeline）**：滚动 7 天排期横向拉通，告别截止日焦虑；
3. **专注计时（Focus Timer）**：依据时间戳补算经过时间；手机切后台与锁屏曾在 HONOR 80 上做约 20 秒短测；
4. **桌面悬浮药丸（Mini Capsule）**：一键缩小为微型置顶胶囊，随心拖拽，沉浸伴随心流；
5. **每日日志（Daily Journal）**：免干扰的大书写板，随手记录思考与当日客观事实复盘；
6. **极简纯色美学**：致敬极致纯白（Light）与深邃黑曜石（Dark）的双重现代质感。

## ✨ 核心特性

### 1. 今日聚焦工作台 · 人体工学双栏设计
- **左主栏（60%）待办流**：秒级极速添加、单日待办与跨多天胶囊分流呈现、已完成列表平滑折叠；
- **右副栏（40%）效率伴侣**：内嵌即时微专注时钟与免弹窗自动保存的今日随笔日记本，无需频繁在视图间跳转；
- **防误触内联卡片**：废除引发焦点锁定的系统弹窗，采用 UI 原生确认气泡，保证键盘与打字输入流转顺畅。

### 2. 7 天全景时间轴 · 多日横向连线
- **滚动 7 天排期**：近 2 天历史到未来 4 天全局排期尽收眼底；
- **悬停秒级建任务**：鼠标滑过任意日期卡片即刻浮现快捷新建按钮，自动预设目标日期；
- **多日任务条带化**：跨越多个周期的长期待办以连贯圆角彩条横向拉通，告别任务截止焦虑；
- **历史记录与专注核算**：当日日记高光徽标标记，底部实时统计各日累计专注时长。

### 3. 防休眠绝对时间戳计时器
- **双模自由切换**：默认正向心流秒表，一键切换 25 分钟番茄钟；
- **绝对时间戳比对算法**：杜绝传统 `setInterval` 累加导致的计时漂移，即使系统锁屏、待机休眠数小时，唤醒后依然分秒不差；
- **纯净禅模式 (Zen Mode)**：全屏深邃无干扰界面，巨幅 JetBrains Mono 等宽时间排版，杜绝数字跳动抖动；
- **Web Audio 纯合成禅音**：基于 Web Audio API 本地实时合成清脆提示音，不依赖外部音频文件，零网络延迟。

### 4. 桌面迷你置顶悬浮药丸 (Mini Capsule)
- **单窗口物理变形**：一键将主窗口智能缩小为 `270x90` 像素的悬浮胶囊，自动贴靠屏幕边缘并置顶停留；
- **无缝状态继承**：同一套计时线程持续运行，全屏与悬浮药丸形态之间切换无断点、无延迟、音效准时触发；
- **随心拖拽与微型控制**：药丸任意空白区域支持平滑拖拽，内置开始、暂停、完成按键，双击即可秒级还原为大窗口。

### 5. 每日日志与客观复盘
- **单输入框纸质体验**：宽敞无压迫感的书写抽屉，随手沉淀今日思绪与灵感；
- **客观事实自动汇总**：自动呈现当日累计专注时长与完成清单数，为每日复盘提供真实依据。

### 6. 本地数据与手动备份
- **免注册、零云端依赖**：无需手机号、无账户体系、无需租用任何云服务；
- **明文 JSON 持久化**：所有任务、专注历史与日志均保存在本地磁盘；
- **文件备份与恢复**：支持导出 JSON；导入会整体替换当前数据，操作前自动在本机保存恢复文件。电脑与手机各自新增的数据不会自动合并。

## 🚀 快速开始

### 方式一：一键双击启动（免命令行）
1. 确保电脑已安装 [Node.js](https://nodejs.org/)（推荐 LTS 版本）；
2. 双击项目根目录下的批处理脚本：
   👉 **`启动doin.bat`**
3. 即可在桌面正中央拉起 `doin` 独立运行窗口。

### 方式二：命令行开发与启动
```bash
# 1. 安装项目依赖（首次运行需执行）
npm install

# 2. 启动桌面应用
npm start
```

## 📦 独立桌面打包

项目内置开发用桌面打包工具；面向读者的 Windows 64 位完整文件夹使用 `npm run build` 后再执行 `npm run package:reader` 生成。读者下载时应获取包含整个文件夹的 ZIP，不能只复制 exe：

```bash
# 构建并装配读者版完整文件夹
npm run build
npm run package:reader
```

**产物说明**：
- **绿色免安装主程序**：生成于 `release/doin-win32-x64/doin.exe`
- **专属图标快捷方式**：自动在根目录下创建带海獭图标的 `doin.lnk`

上述 `npm run package` 是原开发版脚本。读者版输出在 `release/doin-reader-<版本>-windows-x64/`，与现有开发版文件夹分开；压缩发布前还需试装、检查内容及生成校验值。

## 🔒 数据主权与备份恢复

> Android 自用调试版已在 HONOR 80（Android 15）用虚构任务验证：七列全景全部展开、跨天任务连续横条、短时切后台与锁屏后秒表和倒计时按经过时间补算。用户曾观察到旧版后台暂停；该描述不适用于 2026-10-04 后的版本。长时间后台、应用进程结束、倒计时到点通知和其他机型尚未验证。手机端没有桌面悬浮胶囊。曾出现一次导入恢复后任务数回退，原因未证实；重要数据请另存外部备份。

用户的全部待办清单、专注记录与每日日志均透明存储在本地：

- **存储格式**：标准 JSON 文本文件（纯明文、无私有加密绑架）；
- **如何导出备份**：
  在【设置 → 导出备份】操作，并核对生成的 `doin-backup-...json` 文件确实存在；桌面顶栏也有导出快捷按钮。Android 需在系统分享菜单中选择本机保存位置；
- **如何恢复数据**：
  点击【导入备份】选择 JSON，核对数据摘要后确认。导入前会保存接收端恢复文件；导入后以来源文件为准，接收端新内容不会自动合并。可在设置中选择“恢复导入前数据”撤销。首次使用前建议另存一份外部备份；
- **当前运行方式**：没有账号或云服务，数据保存在各设备本地。实际设备、网络、存储及开发成本尚未完整统计；本地文件仍可能因误删、设备故障或覆盖导入而丢失，请保留独立备份。

Android 导出通过系统分享菜单选择保存位置。请自行核对文件确实保存成功；分享菜单返回不等于文件已经落盘。导入前的自动恢复文件保存在应用内部，卸载应用或清除应用数据会丢失它，重要数据仍应导出到手机外部或电脑。Android 系统备份已关闭。

手机与电脑之间的文件传输已用虚构数据验证双向导入和恢复。HONOR 80 的“保存（本机）”曾把文件存到“我的手机/我的文件”，需复制到“下载”后电脑才能按常见 USB 文件传输路径找到。当前导入是**整体替换**，两端新增内容不会自动合并；导入前先核对当前与来源摘要，并在接收端留一份外部备份。

### Android 与 Windows 手工复制（HONOR 80 实测）

1. 手机解锁、插入数据线，USB 用途选“传输文件”。电脑按 `Win + E`，在“此电脑 → HONOR 80 → 内部存储 → Download/下载”找手机文件。
2. **手机到电脑**：在手机 doin“设置 → 导出备份 → 保存（本机）”，再用手机文件管理确认文件落盘。如果文件位于“我的手机/我的文件”，先在手机文件管理中**复制**到 Download；再在电脑资源管理器中把 `doin-backup-...json` 从手机 Download **复制**到自己选定的电脑备份目录。成功标志是电脑目录出现同名 JSON。
3. **电脑到手机**：先在电脑 doin“设置 → 导出备份”保存 JSON；在电脑资源管理器中将文件**复制**到 HONOR 80 的 Download。成功标志是手机文件管理的“下载”中出现该文件。
4. 要在另一端使用文件时，再打开该端 doin“设置 → 导入备份”，核对当前与来源的任务、专注、日志数量。确认后会**整体替换**接收端内容；先确保原文件和接收端外部备份各有一份，不要把自动生成的应用内恢复文件当成唯一备份。

以上步骤在 HONOR 80 上用虚构数据试过。手机文件管理的名称可能随系统版本不同；复制时不要选“移动”或覆盖同名旧备份。

## 📱 Android 读者体验版

读者版使用独立包名 `com.doin.reader`，可与自用调试版 `com.doin.personal` 并存；两者数据隔离，不会自动同步。Android 安装包必须使用长期保管的正式签名密钥制作，不能用调试 APK 冒充正式版。签名密钥和密码只存于项目目录外的私人位置，不能提交到 GitHub。完整的小白安装、备份步骤见《读者体验版-安装与备份.md》。
